# K203C statement review coverage

Saved statements now shows a review progress panel for each imported CSV. It displays the imported date range, matched and open row counts, and exact signed totals for the whole statement, matched rows, and open rows. Confirming or correcting a match refreshes this summary immediately.

These counts and totals only describe rows in that saved import. They are not a cleared bank balance or proof that the entire bank statement was imported. Continue to compare real statements and books before treating the records as reconciled.

Verify with the bookkeeping widget suite and a production web build. The backend calculates the summary on read and no schema migration is required.

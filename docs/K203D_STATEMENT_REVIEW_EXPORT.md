# K203D saved statement review export

Open **Saved statements**, choose an import, then use **Export review CSV**. The exported file includes current match status for every saved row and the chronological match and correction history. This can support owner or accountant review, but does not replace the original bank statement and does not establish cleared balances or complete reconciliation.

The export is requested while the owner is signed in; authorization failures clear private data. The existing platform file saving flow is used on web and mobile. A successful export shows a brief confirmation; errors are displayed in the statement dialog. There is no schema migration.

Verify with the bookkeeping widget suite and production web build.

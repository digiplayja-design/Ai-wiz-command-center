# Receipt WIZ 1.2.0 (3) release verification — 29 October 2026

Scope: upgrade the existing Android app `com.korlixdeveloper.receiptwiz` and prepare its first iOS TestFlight release. Public Apple App Review is a later step after testing.

## Changes

- Explicit Upload receipt files action (JPG/JPEG, PNG, WebP, PDF, 8 MB each).
- Batch imports: at most 10 files and 40 MB total, confirmation before uploading, optional consented AI reading, per-file progress, stop after the current request, exact-duplicate reuse and stable upload retry keys.
- Originals survive failed scans. Saved files are not reuploaded on retries. Switching accounts clears the active queue and rejects late responses.
- Bounded camera reads, functioning replacement-file selection, corrected delete/back navigation, last-page recovery after deletion, and CSV exports across all filtered receipts.
- Red version of the existing KORLIX logo, generated by editing the original with image_gen; platform icons generated by flutter_launcher_icons. Updated actual-app store screenshots include the import preview.
- iOS native-picker location-purpose declaration and artifact validation. The declaration does not enable optional geotagging or request location access.
- Dedicated iOS signing/candidate/TestFlight workflows. Existing distribution identity is reused; no private key is generated or exported. Only the Receipt WIZ bundle/profile can be created.

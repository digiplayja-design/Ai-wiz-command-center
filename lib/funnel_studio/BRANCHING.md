# K154 — Conditional inquiry questions

Open **Page → Make it yours → Inquiry questions**. Add a multiple-choice question,
then set a later question's **Show this question** selector to that source.
Choose the triggering value in **Answer equals**. Leave **Always** for questions
every visitor should see. A required conditional question is required only when
its path is shown. Up to four total questions can form a chain.

Use Preview and select sample choices to explore each path. In guided mode,
**2 · Request** shows the interactive choices and **3 · Review** shows that path
with synthetic contact/text details. Preview answers are never saved or sent.
Changing the question definitions resets preview answers.

Save draft preserves unfinished conditions. Publication requires an earlier
multiple-choice source and one of its current options. Reordering, removing a
source, changing its type, or removing an option can require condition repair;
the editor and launch checklist explain this. Removing a source deliberately
clears dependent trigger choices, preventing silent reconnection if its ID is
reused. NOVA copy generation, duplicate draft, and reload retain saved rules.

Public questions update when the visitor changes a choice. Hidden branches are
cleared and omitted from capture, review, Leads and CSV. If the browser enhancement
cannot run, **Update questions** reveals the selected path without creating an
inquiry; visitors then confirm consent before submitting. Earlier submitted
answers remain unchanged when page definitions change later.

Deployment does not publish an owner's funnel. User tests remain deferred. Add
about five minutes to final acceptance to check both paths, a chained required
question, switching away from a filled branch, final guided review, and the
resulting Leads/CSV. Booking links/routing and ads are separate work.

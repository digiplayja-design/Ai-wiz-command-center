# K151 — Page images

In **Page → Make it yours → Page images**, choose a logo or main image. Upload
one still JPG, PNG or WebP (up to 5 MB and 16 megapixels), or select a saved image.
Review the optimized image and enter a useful description for screen readers.
Save the draft, review the page, and publish when ready. Uploading and selecting
do not publish the image. Pages without images keep their existing layout.

**Remove** clears only that draft's image selection. To permanently delete an
unused asset, open **Choose logo** or **Choose main image**, then **Delete** and
confirm. Images used by saved drafts or published snapshots, including paused
pages, are protected. Remove references and save/republish those pages first.
The library supports 50 optimized images, totaling up to 20 MB, per owner.

The library is shared only across the current owner's Funnel Studio pages.
NOVA-generated copy and duplicated drafts keep image references. Thumbnail
requests use authenticated JSON responses and memory images; no access token is
placed in an image URL. Account access loss clears the picker and image widgets.
If upload receipt is uncertain, refresh the library; repeating the same image
reuses its optimized bytes. No automatic unused-image purge runs.

This increment supports logos and one main image, not videos, arbitrary blocks,
image editing, galleries on public pages, custom domains or advertising assets.

Deferred user checks: select an image using the actual iPad/phone picker, inspect
its optimized result and description, save without changing the live page,
publish deliberately, view the live image, reuse it on a duplicate, and check
remove/delete protection using an intentionally disposable image. Images visible
on a published page can be downloaded by visitors. Pausing blocks future server
reads; it cannot retract previously downloaded copies.

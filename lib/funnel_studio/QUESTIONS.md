# K153 — Inquiry questions

Open **Page → Make it yours → Inquiry questions**. Add up to four questions and
choose **Text answer** or **Multiple choice**. Mark each required or optional.
Use arrows to reorder, or remove a question from the current draft.

Question labels allow 120 characters. Text answers allow 500 characters.
Multiple-choice questions use one choice per line: 2–8 distinct choices, each up
to 80 characters. Finish labels and choices before publishing; the checklist
flags incomplete definitions. You can save an unfinished draft.

The preview shows questions in the inquiry form. For guided forms, use **2 ·
Request** to inspect questions and **3 · Review** for synthetic sample answers.
Preview interaction does not create an inquiry. **Save draft** preserves your
questions without changing the live form; **Review & publish** updates it.
NOVA copy generation and duplicated drafts preserve questions and choices.
**Reload saved → Discard edits** restores the last saved definitions.

After a visitor submits, open **Leads → Question answers** on their inquiry.
The original question wording and submitted answers remain available after later
page edits. Optional unanswered questions say **Not provided**. CSV export adds
question/answer text as its final column. Answers remain with the inquiry and
are removed if that inquiry is deliberately deleted through existing cleanup.

Existing inbox search still matches contact details and the message. Custom
answers do not automatically change contact permissions, lead status, routing,
booking or follow-up content. Those are separate controls/work.

Deferred owner walkthrough: add one required text question and one optional
multiple-choice question, check the guided preview on the iPad/phone, save then
publish deliberately, submit a disposable test inquiry, inspect Leads/export,
and verify a later wording change preserves that inquiry's original question.
No owner test or live inquiry is requested during development.

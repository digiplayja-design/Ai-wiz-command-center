# K147 · Funnel rehearsal

Open **Run rehearsal** from a selected funnel, or choose the **Rehearsal** tab.
Select the current editor draft or the published snapshot, then a complete
inquiry, missing response consent, or invalid email example. **Run sample**
returns page validation, sample validation, a thank-you preview and the review
tasks the saved workflow would prepare. Draft mode includes unsaved edits and
explicitly assumes publication after review. Published mode respects current
page availability and ignores newer draft content.

The feature makes only a rehearsal request. It never saves, publishes, captures
a lead, changes a contact, initializes settings, reconciles tasks, sends outreach
or launches advertising. A fresh run retrieves current saved workflow settings.
Changing source/scenario clears the prior report; navigation discards it.
Access denial removes the report. Concurrent page edits require a reload.

This is a simulation, not a replacement for live acceptance. Form cookies,
throttling, existing contact permission checks, provider readiness, email
delivery, live lead creation and CSV download require separate verification.
K146 inquiry/search/filter/pagination/CSV live acceptance is explicitly deferred
by Ricardo. The authenticated empty inbox has been observed on his iPad.
Meta activation also remains deferred.

Checklist **Edit privacy URL** and **Edit contact email** links switch to Page,
scroll to the matching field and focus it. **Edit page details** reveals the
first field. **Preview page** and **Run rehearsal** reveal their sections.

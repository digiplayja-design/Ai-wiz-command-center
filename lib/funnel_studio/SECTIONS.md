# K152 — Page sections

Open **Page → Make it yours → Page sections**. Use the arrows to reorder the
main image, benefits, inquiry form and questions/answers below the fixed headline.
Benefits and questions/answers can be hidden without deleting their copy. Remove
an unwanted main image in **Page images**. The inquiry form stays on every page.

**Add text section** inserts a section before the inquiry form. Add up to four,
each with a heading (120 characters) and plain-text copy (1,000 characters).
Line breaks are retained. Both fields are required for publication; unfinished
sections can be saved as drafts. The launch checklist flags unfinished sections.
Remove affects the current draft; **Reload saved → Discard edits** restores the
saved version. The total page also has a size limit; shorten copy if prompted.

Changes appear in the preview immediately. **Save draft** preserves them without
changing the published page. **Review & publish** deliberately replaces the live
snapshot. NOVA copy generation and draft duplication preserve section order,
visibility and added text. Existing pages keep their original order until edited.

The current inquiry form style, consent, review step and final submission stay
unchanged. This release arranges content within one page. Multi-page branching,
custom form fields, videos and rich-text/HTML blocks remain separate work.

Deferred owner checks: reorder sections, hide/reveal benefits, add a text section,
check the preview on an iPad/phone, save without changing the live page, then
publish deliberately and confirm the same order. Include one guided-form inquiry
in the combined end-to-end acceptance pass. No real inquiry or advertising
activation is performed by the automated checks.

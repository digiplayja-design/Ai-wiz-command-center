# KORLIX Logo Studio

Open from the home screen's For business section or More tools. Users enter a brand brief, see a live preview, and choose one of six locally composed directions. Quick-start styles preserve the brand name and tagline. Compare up to three favorites, explore more directions without losing the selected edit, and refine the mark/layout/colors/type treatment. Website, business-card, and profile mockups follow the current design. Local generation does not call an AI service or consume a generation credit.

The optional AI exploration action uses the existing authenticated ImagineClient and `/api/image/create`, with the existing consent, quota, and billing checks. A session gallery lets users select and download recent artwork with its original brand filename. Downloads verify that the selected PNG decodes completely. AI artwork remains PNG and is clearly separate from editable vector designs. This feature does not vectorize AI artwork, promise uniqueness, or perform trademark clearance.

SVG and Canvas share fitted geometry and measured lettering calculations, including long-name fitting and proportional safe space. SVG embeds the matching Roboto fonts and retains editable text. PNG exports contain real alpha transparency. PNG and SVG downloads use the selected background, color/black/white ink, and standard/wide/square/profile preset; the preview uses those same settings. Profile marks are square and fill the canvas with safe padding. Brand kits contain color/black/white SVG and PNG, four layout variants, social assets, a PDF guide, licensed fonts, and a versioned JSON project. Some SVG editors require installation of the bundled fonts.

Projects are explicitly saved to account-scoped local preferences, up to 20. Saving an open project updates it; Save a copy creates another project. Unsaved changes are tracked across edits and delayed writes. New brand clears the current design, shortlist, and AI session gallery. Projects do not sync across devices; JSON import/export provides portability. Import accepts only bounded structured project data, not SVG or executable markup. Account/session changes clear visible designs and ignore pending loads or exports. No database or backend changes are required.
